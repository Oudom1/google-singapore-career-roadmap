# Google Singapore Career Roadmap

A standalone responsive single-page career-planning website for targeting Google technical roles in Singapore.

## Run
Open `index.html` directly in a browser, or serve the folder using any static file server. No install/build required.

## Features
- 12-month 24-task roadmap with local progress tracking
- Technical Solutions Engineer primary pathway and security/SRE paths
- Skills, portfolio case studies, official learning and job links
- Job applications tracker saved in browser localStorage
- JSON progress export/import

## Privacy
All progress is local to the browser; no server account or data submission. Never enter confidential corporate information.

## Deployment
Use GitHub Pages or another static hosting service. Configure a deployment separately and verify the live URL.

Not affiliated with Google. Jobs, availability and hiring requirements change.
